# 📊 InsightIQ

InsightIQ is an AI-powered Business Intelligence dashboard built with Python and Streamlit.

## Features

- CSV & Excel upload
- Automatic data cleaning
- Interactive dashboards
- AI-generated business insights
- Product filtering
- Revenue analytics

## Tech Stack

- Python
- Streamlit
- Pandas
- Plotly
- Git & GitHub

## Future Features

- Sales forecasting
- PDF report generation
- AI chatbot
- User authentication
